# Dors - Учебный проект

Проект для Roblox Studio в стиле игры Doors.

## Что внутри
- `HighlightItems.client.lua` — подсветка предметов (ключи, золото, двери) через теги.
- `DoorSystem.server.lua` — система открытия дверей ключом.
- `GoldSystem.server.lua` — сбор золота и добавление его в статистику игрока.

## Как использовать
1. Открой Roblox Studio.
2. Скопируй скрипты в соответствующие места (указано в комментариях).
3. Не забудь поставить теги на предметы (Key, Gold, Door).
